# Optimizing Well-Being: Unveiling Eustress and Distress through Machine Learning

This is the repository accompanying the study **_Optimizing Well-Being: Unveiling Eustress and Distress through Machine Learning_**.

## 📚 Authors
- Ashutosh Singh  
- Khushdeep Singh  
- Amit Kumar  
- Abhishek Shrivastava  
- Santosh Kumar  

## 📊 Dataset
The dataset used in this study is publicly available on Kaggle:  

**[College Student Stress and Well-being Dataset](https://www.kaggle.com/datasets/ashutoshsingh22102/stress-and-well-being-data-of-college-students/data)**  

> 🔗 _Note: The dataset contains anonymized responses collected from college students to analyze stress, eustress, and well-being patterns._
